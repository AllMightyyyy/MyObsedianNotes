# Phase 2: System Architecture Design

## 1. Architectural Diagram
Design the interaction between components for a high-level view:

```plaintext
+------------------+          +------------------+          +------------------+
|   IntelliJ IDE   | <------> |    Backend API   | <------> | Mobile/Desktop   |
|  (Plugin Client) |          |   (Spring Boot)  |          |  (Optional App)  |
+------------------+          +------------------+          +------------------+
        ^                             ^
        |                             |
        +-----------+         +-------+-------+
                    |         |               |
               Clipboard   Database       WebSocket/SSE
               Access      (PostgreSQL)
```
## 2. Component Breakdown

### IntelliJ Plugin Client

- Captures clipboard data.
- Communicates with Backend API for saving and retrieving clipboard history.
- Provides UI within IntelliJ for accessing clipboard history.

### Backend API

- Handles user authentication and authorization.
- Manages clipboard data storage and retrieval.
- Handles real-time synchronization via WebSockets or SSE.
- Ensures data encryption and secure communication.

### Database

- Stores encrypted clipboard data along with metadata (timestamps, device info).

### Mobile/Desktop Client (Optional)

- Provides access to clipboard history on other devices.
- Syncs with Backend API similar to the IntelliJ plugin.
